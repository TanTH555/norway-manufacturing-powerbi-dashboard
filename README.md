# Manufacturing Performance Dashboard — Norway (Power BI project)
1. Extract the whole zip, open **Manufacturing_Dashboard.pbip** in Power BI Desktop, click Home > Refresh. Data is embedded (no file path needed).
2. Optional: File > Save as .pbix.
Pages: Overview · Production Losses · Downtime · Scrap & Quality · NOK Impact · Summary & Notes + hidden Machine Detail drill-through (right-click a machine > Drill through).
Each page has a calculated headline line. NOK assumptions are editable measures (folder "6 Assumptions"). Synthetic data.
